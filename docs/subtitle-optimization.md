# AI 字幕优化

语音转录设置、语音转录队列和字幕管理均提供「优化」与「翻译」两个独立开关。优化默认关闭；只开优化会保留原语言，只开翻译沿用原流程，同时开启时按批进行优化与翻译流水线处理。

第一批优化完成就开始翻译，同时优化第二批；翻译第二批时继续优化第三批。两个阶段最多保留两批在途任务，翻译较慢时优化会等待，避免不断积压。大批输入也会按条数和文字长度拆成小批，结果依次写入字幕文件。优化先保存断点，翻译失败后继续时复用已完成的优化。本地翻译仍遵守现有推理预约和模型驻留边界，退出边界前完成该批任务。

仅开启优化时，每批优化完成后即可写入和显示，不必等待整段识别结果处理完。同时开启翻译时，每批先优化、再翻译优化后的文字，并在该批译文完成后一起发布优化字幕和对应译文；优化进度可能暂时领先已显示的字幕。

点击优化旁的设置可选择 AI 接口、查看和编辑默认提示词、恢复默认提示词及预览自动背景。优化与翻译共用接口管理列表，可以选择同一接口，也可以选择不同地址或不同模型。密钥仍保存在系统安全存储中，不写入任务文件。

优化设置沿用翻译设置的模型选择和接口管理样式。可在「优化模型」中直接切换已保存的配置，通过「管理 AI 接口与模型」新增或编辑自定义 API 与模型。「提示词」按钮直接打开可编辑的完整提示词，默认展开，无需寻找隐藏入口。

模型中心首页同样提供「字幕优化」卡片，与转录、翻译共用卡片和选择器样式。可以直接开关优化、选择独立模型或跟随翻译的 AI 接口，管理共用接口并打开完整提示词。卡片与字幕管理、转录队列共用配置，修改对之后新建任务生效；专用的「转录设置」页面仍只显示转录选项。

字幕管理、转录面板和队列在每批优化结果保存后立即显示「优化 已完成条数/总条数」。本地或流式识别尚未结束时，分母标明「已识别」，识别结束后才视为最终总数。恢复任务时包含已保存的结果，不重复计数或调用接口。优化与翻译同时开启时分别显示进度。

优化使用支持指令的 AI 接口，也可配置本地 OpenAI 兼容服务。必应的固定翻译接口不接受校对提示词，内置本地翻译入口尚无完整的优化适配，均不列为优化服务。

背景优先使用当前任务已有的视频标题、简短简介和标签；完整版还会读取对应播客单集和哔哩哔哩视频的已有本地元信息。缺失字段直接跳过，不额外联网补查，也不调用 AI 总结简介。每个任务分别截取并保存背景，不使用播放器当前视频的全局信息。背景仅辅助纠错，不可作为字幕中新增内容的依据。

处理按批进行，不生成额外逐字稿，不为优化增加音频上传或逐字对齐。每条字幕的编号和句级起止时间保持不变；文字改动后清除失效的逐字索引。优化请求仅发送字幕文字、提示词和有限背景，不发送媒体文件或本地路径。

正常批次之间没有固定等待；优化与翻译共用接口请求额度，遇到实际限流时短暂退避。优化返回的编号、条数或改写幅度不符合约定时，只补试一次，仍不合格则保留该批原文并显示提示。网络、认证等失败会保留已完成的进度，继续任务会复用已完成的优化结果。

开始任务时保存接口、模型、提示词和背景快照，之后修改全局配置不会改动正在运行或已开始排队的任务。恢复继续使用原配置，显式重新生成才采用新配置。旧任务保持原行为，不会自动开启优化。字幕管理处理已有文件时保留原文件，另存优化字幕和可选译文。

设置导出只包含字幕优化的全局开关和提示词；AI 接口连接、凭据及单个视频的背景仍留在本机。导出过程不会改变本机设置，也不增加导入或自动恢复功能。
