# 统一网络设置与 iOS YTDLP 交付记录

更新日期：2026-10-18。本记录区分代码实现、构建验证与设备实测；尚未完成的平台实测不能视为已通过。

## 使用入口和默认行为

B 站账号页底部（未登录也可进入）、软件通用设置和 YTDLP 下载页的网络设置入口均打开同一页面。

| 功能 | 新安装默认方式 |
| --- | --- |
| B 站页面、登录、图片、播放、下载及 YTDLP 中的 B 站来源 | 不使用系统代理 |
| 网盘登录、目录、封面、字幕、播放及下载 | 不使用系统代理（可独立更改） |
| YTDLP 已识别的国内来源 | 不使用系统代理 |
| YTDLP 国外或未知来源 | 跟随设备网络 |
| 语音识别接口 | 不使用系统代理 |
| 云端转录（ElevenLabs、Soniox、AssemblyAI、Deepgram、Google Gemini） | 跟随设备网络 |
| 字幕翻译、组件更新、其他联网功能 | 跟随设备网络 |

旧 YTDLP 自定义代理启用时，迁移后继续用于国外和未知来源。未启用的旧地址也保留到共用代理配置，不改变其他功能的默认方式。

2026-10-31 新增“云端转录”独立范围，模型列表、上传、提交、查询、结果和清理均走该范围；旧配置缺失此字段时采用跟随设备网络。整体网络方式继续优先，公益接口策略保留。云端会话按线路复用连接及代理隧道，新请求在网络变化后采用新线路，已发送上传不自动重放；继续验证证书，代理失败不隐式直连。详细超时、并发和验证边界见[云端转录说明](cloud-transcription.md)。

网盘从“其他联网功能”独立为自己的网络选项，百度和夸克默认直连。旧配置中曾明确将“其他联网功能”设为自定义代理时，网盘迁移后保留该选择；修改其他功能的策略不再触发网盘重建。夸克原画在本机当前系统代理下有首帧预热超时、直连后成功交接的实际对照记录，见 `docs/quark-playback-validation.md`。

页面顶部提供“整体网络方式”：按功能分别设置（默认）、统一跟随设备网络、统一不使用系统代理、统一使用自定义代理。统一方式优先于分项和下载任务的单独选择，也覆盖播客；切回分项后恢复先前选择。旧配置不含统一选项时继续沿用原有分项。统一自定义代理尚未配置时，先展开表单，代理保存成功后一次性应用。

每项功能可选择跟随设备网络、不使用系统代理或自定义代理。自定义表单默认收起，共用一份 HTTP、HTTPS 或 SOCKS5 配置，可填写账号密码。选择立即显示操作反馈，保存成功才发布新配置；失败保留之前已应用的配置。密码不可读取时阻止外网请求，允许重新保存密码，不自动换成直接连接。AI 字幕翻译请求及接口连接测试均使用“字幕翻译”范围。

浏览器导入队列允许每个任务单独覆盖网络方式：跟随软件设置、直连、设备代理或自定义代理。默认跟随“其他联网功能”，包括队列调用的后台 YTDLP 页面解析、HTTP/HLS/DASH、音视频、密钥及字幕请求；独立 YTDLP 下载页仍按原来的国内/国外来源分类。覆盖策略不修改共享配置，各任务可并行走不同线路，CDN 重定向保留任务选择。任务切换方式时保存断点并等待旧传输退出，原来手动暂停的任务仍暂停，切换期间再次暂停或全部暂停优先。策略名称保存在任务索引，代理地址和密码只使用共享网络设置；网页浏览本身仍遵循浏览器网络策略。队列设置内及任务网络面板均提供进入共用网络设置的入口。

国内来源使用明确域名及合法子域名名单：B 站、抖音、快手、小红书、微博、AcFun、爱奇艺、优酷、西瓜视频、今日头条、腾讯视频及已列出的分享域名。域名边界匹配，不根据 `.cn` 后缀、服务器位置判断。分享地址还原后确定来源；解析、封面、字幕、媒体下载和重试使用来源所属范围，CDN 域名不改变范围。

“不使用系统代理”仍服从操作系统网络路由。接管全设备流量的 VPN 可能继续影响连接，软件无法保证绕过这样的 VPN。[Android 官方 VPN 路由说明](https://developer.android.com/develop/connectivity/vpn)

## 持久化、请求和任务恢复

实现入口是 `lib/services/network/`，包括数据模型、设置服务、系统代理解析、回环网络桥接、Dio/HTTP 接入、图片加载和网页代理配置。

- 配置采用版本化文件 `network_settings_v1.json`、SHA-256 校验、临时文件替换及有效备份。串行提交以最后一次有效选择为准；首次外网请求等待加载和迁移。两个文件均损坏时阻止外网请求并显示失败。
- 密码由现有安全存储保存；配置、任务记录和子程序参数不包含代理密码。新密码先写入并读回验证，再提交配置。旧 YTDLP 地址和任务中的代理字段在迁移验证后清理，其他下载配置及任务记录保留。
- Dio、直接 HTTP、B 站图片和视频网关、下载、字幕、更新及外部联网程序使用统一范围。外部程序通过仅绑定本机回环地址的桥接联网，清理继承的代理环境。本机视频网关连接直接访问；实际外网请求使用选定方式。HTTPS 保持证书验证。
- 设置变更不再主动破坏在途传输。公共回环桥接在每个新建连接上采用最新配置，旧连接尽量完成；成功返回的数据不会仅因网络代次变化被丢弃。提交中的账号操作和语音识别不自动重发。自定义代理失败保留用户选择，有限重试，不回退直接连接。
- 健康的 B 站和网盘播放会话在网络切换时保留原控制器、位置、暂停状态、清晰度与倍速。网关优先重连上游，已失败的播放会话才进入重建恢复。
- B 站下载保留已验证片段后恢复。YTDLP 保留暂停和网络失败任务的临时文件，等待旧任务真正停止后启动新任务；优先下载操作也保留续传文件。
- Android/iOS 的嵌入式下载器对 HTTP 续传保存文件 SHA-256、格式身份和强 ETag，恢复前检查本地文件及远端身份。文件损坏、远端变化或缺少可靠验证条件时重下受影响格式；不影响另一个已验证音视频文件。无法验证的片段残留会重下受影响格式。桌面独立 yt-dlp（以及未使用校验桥接的下载路径）缺少同等校验，使用 `--no-continue` 重新下载未完成文件，保留禁止强制覆盖已完成文件的选项；不盲目拼接旧断点。
- 恢复焦点、最小化恢复及控制中心开关不再被视为网络切换；设备网络和代理变更由原生通知发布。Android/iOS 的普通传输在真正后台被打断后等待返回前台再消耗重试预算；已有连接仍可继续传输。用户主动暂停和取消优先于自动恢复。系统结束进程后的恢复仍依赖各下载器已有的持久化任务记录，不承诺 Dart 任务在系统挂起后持续运行。
- 播客下载、网盘素材、网页/抖音下载及 B 站素材采用可取消的退避等待。转录、OCR、视频合成使用共用素材下载器，临时断网时保留已接收字节；续传校验强 ETag/Last-Modified、Content-Range 和总长度，变化时重取相应资源，禁止拼接不同文件。网盘、网页和播客播放网关对可验证的媒体从缺失字节续接，保持播放器收到的本地响应连续。无可靠验证信息时不冒险拼接。

已完成下载、账号信息和有效缓存保留。本次未加入网络诊断、推荐改设置或线路推荐。

| iOS | CFNetwork/PAC、网络与代理变化、内置 Python/JS 下载器、FFmpegKit 收尾、前后台任务接口 | 构建输入和宿主 Python 测试通过；没有 Xcode/iOS 设备，未编译、签名、安装或实测 |

设备范围沿用工程现有最低系统版本和架构。Android 当前 target SDK 34 不额外申请未来版本的局域网运行时权限；升级目标 SDK 后应依据实际连接与系统要求适配。[Android 官方本地网络权限说明](https://developer.android.com/privacy-and-security/local-network-permission)

Apple 普通公网和本机回环访问不额外弹权限；访问局域网代理可能触发系统本地网络授权。已添加用途描述，拒绝授权后的连接失败不自动切换网络方式；授权、拒绝及撤销流程仍需真实 Apple 设备验证。[Apple 本地网络说明](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)

Apple 的独立网页代理使用公开 `WKWebsiteDataStore.proxyConfigurations`，需要 iOS 17/macOS 14。较早系统的网页组件仅允许跟随设备网络，独立直接/自定义方式显示明确限制；应用的 HTTP、B 站及 YTDLP 下载路径不依赖这个 WebKit 接口。[Apple 接口说明](https://developer.apple.com/documentation/webkit/wkwebsitedatastore/proxyconfigurations-6g21z)

Android/Apple 共用网页存储时，不同时打开使用不同网络范围的网页窗口，避免一个窗口覆盖另一个窗口的代理。Linux 重新连接遗留专用浏览器时检查真实启动参数和专用资料目录；旧桥接地址失效时只关闭已确认属于该功能的浏览器，然后按当前地址重启。无法确认时阻止使用，不关闭其他浏览器。

HTTPS 网页的 CONNECT 隧道不暴露内部请求方法；网络切换可使网页当前请求失败，但软件不会自动重发登录。第三方桌面 CLI 若内部另配网络或忽略代理环境，其行为仍需按具体工具验证，不能承诺控制任意程序的网络。

## iOS 内置运行时

`packages/ios_ytdlp/runtime.lock.json` 锁定 CPython 3.13、yt-dlp 2026.10.21、EJS 0.8.0、QuickJS-NG 0.17.0 与配套纯 Python 依赖，所有构建输入有 SHA-256 校验。设备 arm64 和模拟器 arm64/x86_64 输入已准备；第三方二进制缓存放在被 Git 忽略的 Vendor 目录。

运行时随应用发布，进程内调用 Python 和 QuickJS；不依赖服务器、独立 JS 程序或在应用运行期间下载执行组件。通过 yt-dlp 公开 JS Challenge Provider 接口处理挑战，禁用外部 JS 和远程组件。运行能力信息显示内置运行时和版本。

音视频分别下载后使用已有 FFmpegKit 合并，最后验证轨道，防止只有画面或声音的文件被标成完整成功。原生事件接入现有解析、进度、暂停、取消与恢复接口。上述原生调用、系统后台挂起和实际国内网站/YouTube 完整流程尚需 iOS 设备验证，宿主 Python 测试不能代替这些检查。

构建准备：

```sh
python3 tool/prepare_ios_runtime.py
flutter pub get
cd ios
pod install
```

Podfile 在安装时准备校验后的运行时，Runner 构建阶段执行 `tool/install_ios_runtime.py`，按目标架构放置 Python 标准库及扩展框架，写入 `.fwork`/`.origin` 标记并随应用签名。每次构建复制当前共用 Python 源码，避免缓存的 Pod 安装遗留旧下载逻辑。[Python 官方 iOS 嵌入说明](https://docs.python.org/3.13/using/ios.html)

## 2026-10-18 播客自动连接补充

按功能分别设置时，播客订阅、搜索、播放和下载使用独立自动选路，封面也使用自动域名分类。国内优先直连、海外优先设备代理/PAC；域名跳转重新分类。健康连接不因媒体库的功能代理设置变更而中断，连接故障时对单一主机十分钟内最多试一次备用设备线路。自动模式不使用共用自定义代理；旧播客分项记录保留兼容，设置页以“播客 · 自动连接”说明替代两个下拉框。选择统一方式后，播客新连接使用该方式，不再因连接故障自动改走备用线路。外网新连接先加载共用网络配置，避免首次连接绕过已经保存的统一策略；本机回环连接仍直连。

下载使用经验证后启用的两个 16 MiB 窗口、独立连接池及前后台共用的连接租约。429/503 全域名共享冷却，完整遵守 Retry-After，恢复后降低并发。拒绝、限流、服务端状态和证书错误不会触发线路切换。暂停、取消、断流恢复及字幕管理中停止转录的行为见 `docs/podcasts.md`。这不构成固定带宽或零风控承诺。

## 2026-10-19 网络请求生命周期排查

排查范围包括共用 HTTP/Dio、代理桥接、播客、B 站、网盘播放和素材、网页及抖音下载、字幕搜索与字体、模型下载、AI 请求、WebDAV 和局域网传输。修复前保存了相关工作区文件，并以真实回环 HTTP/TLS、代理和断流服务复现；没有把第三方站点限制当作软件错误，也没有调整设备正在使用的代理。

- 共用请求打开函数在超时或取消后中止迟到的请求，避免调用已经返回失败后仍提交请求。共用响应读取器在超时、超限和错误退出时取消实际订阅，分别限制空闲时间和总时间；大小上限按解压后的字节执行，压缩传输长度不冒充图片解码后的进度总数。
- Dio 流式响应采用独立子取消信号。停止读取、拒绝响应或读取发生错误时释放本次连接，取消一个分片、测速或播放器读取不取消其父任务和其他并行请求。接入网页、抖音、字幕、B 站媒体及探测、模型和字体下载；不改变各自的状态判断、续传校验、测速排序、校验和及进度规则。
- 跳转和拒绝响应不再等待无用的响应内容结束。网盘的播放、探测和素材下载保留 Range/If-Range；没有目标地址回调时仅保留媒体协商头，Cookie、认证和供应商自定义头仍须按目标地址重新确认。网盘 API 的多次跳转、响应头及内容共用原来的总期限，取消监听在结束后解除。
- 网盘素材保留签名刷新、版本变化重下及 416 完整性判断；播放列表增加 8 MiB 和 30 秒的读取限制，并在所有退出路径关闭连接。X 公开状态回退接口增加 4 MiB、20 秒的内容读取限制，失败时仍沿用已有回退顺序。
- 公网 HTTPS WebDAV 使用“其他联网功能”的共用设置。家庭 NAS 的本地 IP 和 localhost 继续直连，修复 IPv6 回环地址识别。已提交的同步写入保持原网络快照，不新增自动重发；仍拒绝重定向和公网明文 HTTP，保留不可覆盖的事件文件及同步合并规则。
- 单张网络图片增加连接、响应和内容期限，已成功下载的图片不再仅因网络代次更新而报错。共享封面读取的连接、响应头和内容共用既有总预算，错误响应立即释放；保留合并相同图片请求、缓存和备用封面的规则。B 站封面的既有大小限制在读取过程中执行，保留原 URL 白名单。
- 播放中继及时发送首批小数据，并在播放取消/关闭时释放正在等待下一个数据块的请求。代理桥接将尚在握手的连接纳入关闭处理；CONNECT/SOCKS 握手增加 20 秒总期限，防止持续少量数据把等待无限延长。静默的远端断连仍由现有空闲期限兜底。

上述改动保留 TLS 证书验证、用户指定的网络方式、账号隔离、可验证的续传拼接和局域网传输目的。AI 等受保护提交继续使用原有取消及重试规则。B 站旧测试对 CDN 短暂断线一律要求重新获取播放地址，与已有的原线路恢复逻辑不符；测试现分别验证原线路恢复和重试耗尽后刷新，未为满足旧断言修改生产播放逻辑。

本轮日志、修复前快照和最终测试清单在 `.artifacts/network-audit-20261019/`。平台运行验证以实际执行的宿主和构建记录为准，不把回环测试当作所有平台或关闭代理后的中国大陆网络实测。
