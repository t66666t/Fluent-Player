# 哔哩哔哩多音轨播放

播放器从当前账号的 playurl 响应列出实际可用音轨，包括 `dash.audio`、`dash.flac.audio` 和 `dash.dolby.audio`。继续使用现有登录态、WBI 请求、CDN 网关和播放器依赖；不另行下载解码器。

## 操作与状态

- 音质胶囊位于画质胶囊上方，复用同一控件和弹出菜单。只有提供 Hi-Res 无损、杜比全景声等特殊音轨的视频才显示；普通视频即使有多个 AAC 码率或 Opus 音轨，也不显示额外入口。
- 尚未记忆在线音质时，自动选择当前账号实际可用的最佳音轨，按 Hi-Res 无损、杜比全景声、其他普通音频排序，同类选择较高码率；首次进入可用的特殊音质直接呈粉色。用户手动切回普通音质后，胶囊灰色显示特殊音质名称，并记住这个选择。已有手动记忆始终优先；自动选择不写入手动偏好。没有可播放特殊音轨时不显示音质入口，使用可用的普通音频。
- 菜单每种特殊音质只列一次，并提供一个“普通音质”选项，普通音质内部选择可用的较高码率 AAC，不展示编码或码率细分。真正完成切换后，特殊音质名称变为粉色；菜单标出当前音质类别。切回普通音质后，特殊名称恢复灰色。
- 在线音轨在成功应用后持久保存为全局默认，后续视频及重启后优先采用相同音轨版本。当前账号不提供该版本时回退到可用的较好音轨，原偏好仍保留；再次遇到支持该版本的视频时自动恢复。候选播放器准备失败不会改写默认。
- 画质切换、播放地址刷新及网络重连保留所选音轨。手动切回本地素材只影响该素材，不清除其他在线视频的全局音质默认。
- 显式选择本地素材会恢复该素材自己的音频。已有合并素材没有可靠的音轨身份，手动选择在线音质后使用对应 DASH 音轨，避免把旧素材的 AAC 标为无损或杜比。

## 播放与恢复

音质和画质共用现有双控制器准备与交接流程。候选播放器静音预热并校准时间，确认准备完成后才替换当前播放器；保留播放/暂停意图、进度、倍速和音量。音质与画质不能并发切换。原生音频解码参数不可用时，切换失败并保留原音轨。

网关仍按音轨 ID 分开缓存，不合并不同格式的音频字节。刷新已打开会话必须找到相同音轨 ID；权限变化导致特殊音轨消失时，不会把 AAC 字节拼接进 FLAC 或 E-AC-3 会话。新建会话可以回退到当前账号可用的音轨，界面显示实际选中的结果。

支持获取并解码 Dolby Digital Plus / Atmos 音轨，不代表实现了 Atmos 对象渲染或 HDMI 压缩码流直通。沿用现有 PCM 输出；设备与系统可能重采样或混为立体声，Hi-Res 的端到端无重采样输出也不在本次实现范围内。

## 下载音质

下载页设置提供“自动最高音质”“Hi-Res无损优先”“杜比全景声优先”“普通音质”。默认自动按无损、杜比、其他已返回格式及普通音轨选择，同类使用较高码率；只考虑当前账号实际返回且含可用地址的音轨，不凭权限显示标志创建不存在的音频。下载偏好与在线音质记忆分开保存。

单视频和分 P 任务仅在存在特殊音轨时显示音质选择行，菜单与在线播放相同，普通音质只保留一个选项。新任务按偏好选取，用户可以单独调整尚未开始的任务；音轨选项、选择和完成后的实际来源音轨随原任务 JSON 保存，旧任务缺少这些可选字段时仍能恢复。已排队、正在处理及已有断点的任务保留原音轨；完成的任务显示实际下载音轨，不被后来修改的偏好覆写。

合并显式映射选择的音频输入，使用流复制；FLAC-in-MP4 按需要添加封装兼容参数，保留原采样与压缩数据。视频兼容性修复时，特殊音频仍流复制，避免悄悄转成 AAC。下载断点继续沿用原音轨身份与现有续传校验，设置变化不会拼入另一种音频格式。

后续下载与记忆验证记录位于 `build/bilibili-audio-download-validation/`。Windows 真实 FFmpeg 检查包括生成的 FLAC/E-AC-3 及前述两条视频的真实前三秒音频：合并及视频修复后的音频包 SHA-256 序列与输入逐包相同，FLAC 保留 24-bit / 96 kHz，E-AC-3 保留 48 kHz / 六声道及真实样本的 Atmos profile。该检查证明下载文件的压缩音频未被降质，不代表播放设备具备 Atmos 对象渲染。

### 竖屏播放器入口

竖屏播放器的画质、音质选择不再依赖横屏底部进度栏。入口位于全屏按钮左侧，宽度不足时音质在上、画质在下，空间足够时紧凑并排显示；根据播放器实际尺寸缩放，高度为 28–34 逻辑像素、单个宽度不超过 144，预留全屏按钮及侧边控件的区域。窄播放器的弹出菜单保留足够宽度，并限制在屏幕安全区域内。没有可获取的特殊音轨时仍不显示音质入口。

竖屏和横屏复用同一胶囊、菜单、切换方法及记忆，不另建视频或音频切换流程。字幕根据同一份按钮几何避让，处理原视频在播放器内留黑边时的坐标换算，并跟随控件显隐；普通字幕仍绘制在控件上方且穿透点击。字幕位置编辑继续保留原有拖动行为。字幕避让开关与横屏共用现有设置。
