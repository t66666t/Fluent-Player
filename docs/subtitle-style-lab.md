# 全局字幕预设（正式版隐藏功能）

2026-09-09。48 套原创调试预设，8 类，每类 6 套。设计参考公开字幕规范与字幕组教程，不声称是字幕组官方配置、人气排行榜或平台认证模板。

## 使用与保存

所有平台的普通 release/debug/profile 构建都包含隐藏入口，无需私人构建开关。

1. 播放媒体时长按倍速按钮，解锁预设入口；单击仍立即打开倍速菜单。
2. 进入字幕样式设置，打开占满边栏可用高度的预设选择页。窄边栏（手机横屏侧栏约 248–360px）使用紧凑顶栏：返回/关闭、分类、定位、搜索为 26–28px 按钮；标题和「使用原样式 / 微调当前预设」优先缩小字号而不是变成省略号。宽栏自动多列。分类按钮在定位左侧，点开后用与卡片同色的芯片筛选 8 类预设，再点按钮、点收起或点分类外即可关闭。搜索单独展开。浏览位置和筛选条件在本次运行内保留，点击定位按钮可清除筛选并跳到当前样式。
3. 点击卡片即应用到全局媒体。点击「微调当前预设」或卡片上的调节按钮，在边栏内部打开微调页，颜色选择也在边栏内展开，视频保持可见。微调其他卡片会先应用该预设，以便实时预览。可修改主副整体字号、各自文字颜色、描边、背景颜色与不透明度、阴影颜色/模糊/偏移。幽灵模式是顶栏里的空心圆勾选（选中为实心），不再占用一整行开关。大小滑块按播放器实际编辑目标显示「普通大小」或「幽灵大小」，各自按预设 id 独立保存 60%–180% 的倍率；从合成页进入始终编辑普通大小。
4. 主副字体和字号比例、顺序、背景形状、内边距维持本套预设的设计。微调独立保存到本预设，可单独重置。
5. 点击「使用原样式」切回原来的字幕设置；隐藏入口仍保留，可通过「选择字幕预设」返回。再次长按倍速会隐藏入口并切回原样式；再次解锁可恢复上次选中的预设。
6. 关闭软件不会清除模式、入口状态、选择或微调。它们存储在独立的全局偏好键中，不覆盖原样式参数。

原样式和预设都可以在播放器里拖动当前字幕。打开样式面板或位置面板即进入编辑：绿色框包住实际字幕块，松手后保存。未拖动过的预设仍使用自己的默认底距和宽度。拖动后的位置按预设 id 分开记在视频和音频上，不改预设的 `bottom`，也不改原样式或其他预设。重置本预设会恢复该预设样式，并清除它的视频和音频位置覆盖。

幽灵模式仍使用共享的 `ghostModeAlignment`，原样式和预设共用这一位置，不写入普通位置。音频、竖屏与合成设置沿用原有开关可见性规则。从合成页打开样式时编辑的是正常字幕位置，不是幽灵位置。幽灵位置不进入合成快照。新的合成任务会带上当时的正常位置快照；没有该字段的旧任务保持原来的预设默认底距。文本字幕覆盖层使用预设内容绘制组件；音乐播放页歌词保持自身字体，不受全局字幕预设影响。图片字幕或已经烧录进视频像素的文字不能换字。

长按倍速切换隐藏入口，单击立即打开菜单，鼠标与触屏行为一致。

2026-10-18：普通与幽灵大小分开。原样式保留现有的两套字号、行距和字距；预设在 `globalSubtitlePresetMode.v1` 的 `ghostTextScales` 中独立保存幽灵倍率，不写入预设合成快照。旧设置首次加载时，将各预设原有的普通倍率复制并保存为幽灵初值，此后修改互不影响。「重置本预设」同时恢复这套预设的两种倍率及共享样式，继续清除视频和音频位置覆盖。字号数值不根据当前视频换算，幽灵位置保持原样。

## 视频合成

预设模式的任务会记录完整预设快照（包含微调参数），保存任务、重启恢复、素材下载后更新路径、失败重试都保留快照。排队后切换全局预设不会改变已排队任务。

使用预设烧录时采用精确渲染，复用播放中的主副字幕绘制组件和位置算法，输出尺寸按目标视频比例重新计算。即使恢复的任务原来选择粗略渲染，只要带有预设快照也走精确路径。原样式仍支持原来的两种渲染模式。仅封装 SRT 软字幕不会保留字形样式，需烧录才能固定显示效果。

## 排版选择与比例

以下为本项目的设计选择，不冒充行业强制标准。720 是现有播放器的参考高度，表内字号均为本项目 Flutter 逻辑字号；不同字体的字面高度不同，与 ASS 的 em/字面度量不能机械互换。

| 类型 | 主字号（720 基准） | 副 / 主 | 实际字体字重 | 排列与用途 |
|---|---:|---:|---|---|
| 通用黑体 | 28–40 | 65–78% | 中文 400/500/700；英文 400/500/600 | 主上副下，电影、剧集 |
| 电影宋体 | 29–36 | 65–80% | 中文 400/700；英文 400 | 宋体配 Brawler/Inter/窄体，文艺历史片 |
| 动漫对白 | 31–40 | 65–80% | 中文 400/500/700；英文 400/700 | 思源黑体配 Comic Relief，较厚黑边 |
| 黄白双语 | 30–40 | 68–78% | 中文 700；英文 600 | 暖黄主字、白色副字 |
| 双语学习 | 29–37 | 72–100% | 主副 500 | 放大副字幕，提供副上主下与等大对照 |
| 纪录访谈 | 28–38 | 66–75% | 中文 400/500/700；英文 500 | 较窄英文，适合长句 |
| 底板易读 | 32–44 | 72–100% | 中文 400/500/700；英文 500 | 35–78% 黑底，复杂背景 |
| 竖屏方屏 | 35–46 | 68–85% | 中文 700；英文 600 | 宽度封顶，10–22% 底距 |

普通预设的缩放参考高度为 `min(视频显示高度, 视频显示宽度)`，普通原样式继续使用视频显示高度；字号和块间距乘以该值 / 720。幽灵原样式与预设统一使用 `min(完整页面高度, 完整页面宽度)`，页面尺寸在安全区和边栏分配之前取得，不扣除软键盘高度。换视频、调整边栏、切换 AI 对话只改变可用布局，不改变幽灵字号；整个窗口尺寸变化才重新适配。

底距是字幕块外缘到定位视口底部的距离，普通竖屏预设至少 10%；左右最多使用定位视口的 86–90%。两轨分别自动折行，保留现有长文本边界处理，不新增按视频比例或句长缩字的规则。

| 视口示例 | 清幕标准主 / 副字号 | 外缘底距 | 说明 |
|---|---:|---:|---|
| 1280 × 720（16:9） | 32 / 21.76 | 32.4 | 正常横屏 |
| 1920 × 804（约 2.39:1） | 35.73 / 24.30 | 36.18 | 宽银幕按实际高度，不把黑边高度计入 |
| 800 × 600（4:3） | 26.67 / 18.13 | 27 | 按实际高度，长句自动折行 |
| 600 × 600（1:1） | 26.67 / 18.13 | 27 | 主副字幕整体居中 |
| 360 × 640（9:16） | 16 / 10.88 | 64 | 大字需求可选「掌心醒目」：主 23 / 副 16.56 |

上表展示普通模式的视频显示区域。幽灵字幕仍在现有可用区域内拖动和避让控件，但字号始终以完整页面短边为基准；定位区域与字号基准分开。软件不自动分析画面中的脸或烧录黑边。已烧录在视频像素中的字幕无法通过这些预设改变。

## 2026-09-19 字形与背景的视觉居中修正

预设主副字幕现在按内置字体和中西文脚本进行光学垂直补偿，补偿量随实际字号与视频参考尺寸一起缩放。文字、描边和阴影整体移动；背景尺寸、内边距、主副间距、对齐位置及保存的数据格式不变。中文字幕使用拉丁字体时，采用实际回退字体 Noto Sans SC 的补偿值。普通自定义样式保持原有行为。

补偿针对字体的稳定字形中心，不随每句字幕的标点或下伸字母重新测量，以免播放时上下跳动。播放、幽灵模式、微调预览和精确合成使用同一绘制组件。真实字体像素测试覆盖 6 字体 × 2 脚本 × 3 字号 × 2 参考尺寸，共 72 组测试句，中心偏差不超过 1.5 逻辑像素；这不是对所有任意文本逐字像素居中的保证。相关回归共 80 项通过。

## 2026-10-18 普通字幕样式页与字体库

普通样式现在提供整体大小（60%–180%，默认 100%），同时保留主、副字号。倍率在统一字幕度量中应用一次，普通与幽灵模式仍各自保存。背景有独立开关，关闭不丢失颜色与不透明度；旧透明背景加载为关闭。字幕轨道、时间轴、主副排列和预设设计保持原有行为。

字体入口在原面板内逐级切换，返回恢复浏览位置，手机系统返回键也按层级处理。字体页提供通用字体、按需添加的语言字体与实际可用字重。旧中文、英文字体及字重继续保留。字体解析优先考虑轨道语言，以假名等文字辅助判断；日文汉字与假名保持一致。手动主、副语言按来源记录，单文件分行的副字幕使用独立来源键，不修改字幕文件。

本地导入支持 TTF/OTF。OpenType 名称、字重、可变字重与 cmap 覆盖在独立任务中读取；文件以 SHA-256 标识并保存在应用支持目录的 `subtitle_fonts` 中，字体库不参与普通缓存清理。导入文件默认授权未知。播放和精确合成使用动态字体加载；近似 ASS 合成共享文字分段解析，并使用隔离的字体目录与实际字体名称。任务使用不可变字体标识，丢失或改变的字体明确报错。

在线索引在 `assets/fonts/licenses/subtitle-font-catalog.json`，通过 `python tool/build_subtitle_font_catalog.py` 从 Google Fonts 官方元数据和固定 Git 提交刷新。当前收录 1,900 个条目：1,899 个具有 OFL 许可和普通字形文件的 Google Fonts 字体族，以及汉仪风尚黑个人版官方获取入口。下载核对上游 Git blob 指纹，并与许可证一起保存。字体的商用许可和允许软件直接下载分别判断；官方个人版只跳转官网获取，再由用户导入。在线未下载的字体不冒充已经渲染的字体预览。

## 字体列表与可变字重

“我的”列表先显示下载或导入的字体，按添加时间倒序排列，其后是内置字体；顺序随字体库记录保存。支持 `wght` 轴的可变字体按其实际范围显示连续滑块，固定字重字体仍显示已有字重选项。已经下载的旧字体在下次加载时读取字重轴，不需要重新下载。

播放与精确合成把滑块值传递给字体渲染器。粗略合成会向 ASS 传递数值字重，但不同版本的字幕渲染器可能无法精确渲染可变字体的中间字重；应使用精确渲染保持画面一致。测试字体仅用于回归测试，不作为应用内置字体打包。

## 在线字体下载前预览

在线字体沿用已下载字体的单行紧凑预览设计，例如“字幕预览 Aa”。简体中文、繁体中文、日语和韩语使用各自的简短文字；支持拉丁字母时在同一行加上 Aa。阿拉伯语和希伯来语使用对应排版方向。预览保持原有小字号和文字颜色，较窄的侧栏省略超出部分；文字缩放受限，不额外添加双行样张、语言标题行或背景卡片。

Google Fonts 字体通过官方 CSS API 的 `text` 参数仅请求固定样张需要的字形，不内置或安装完整字体，不发送当前字幕内容。预览沿用应用网络设置，延迟加载可见行附近的样张，最多同时处理三个请求；离开列表会取消请求。每次样张响应不超过 256 KiB，并验证字体格式和样张字形覆盖；失败时显示重试，不使用系统字体冒充预览。同一样张在本次运行中复用。

样张来自 Google Fonts 当前在线版本，完整下载继续使用目录中固定提交的文件、原有指纹校验和许可证，预览不会改变字体库或合成任务。两者的上游版本可能不同。汉仪个人版等仅提供官网入口的条目保留“官网预览”，不自动获取受限字体。

Noto Color Emoji 的在线接口没有返回足够小的子集，因此仅内置一张约 14 KiB 的官方表情图片样张，完整字体不随应用打包。图片的固定来源、修改记录和 Apache-2.0 许可位于 `assets/fonts/previews/NOTICE.txt` 及 `assets/fonts/licenses/NotoEmoji-Artwork-Apache-2.0.txt`，并登记到应用许可入口。

本轮补充目录内九个字体的高棉语、老挝语、缅甸语、泰米尔语和吕基亚文标记，未更新下载提交、文件或指纹。原生样张复测可显式运行 `python tool/fetch_subtitle_font_preview_fixtures.py`，再以环境变量 `SUBTITLE_FONT_NATIVE_PREVIEWS=1` 运行 `test/subtitle_font_preview_native_test.dart`；下载仅写入构建目录。

## 普通悬浮字幕的英文背景对齐

普通样式的背景原来只包住字体行框；字体声明的上升部、下降部不等于可见字母的范围。英文小写正文、带下伸字母的句子与全大写句子的留白因此不同。双语又共用一个段落，主、副轨的字号和行高差会影响背景最外侧留白。

普通样式现在按字体的 cap-height/x-height 和实际排版基线计算稳定的英文补偿，随字号缩放。内置字体的度量与原字体文件校验；导入字体在已有加载流程中读取 OS/2，旧 TrueType 字体可读取 H/x 轮廓边界。度量仅在内存中保存，不改变字体文件、字体库格式或任务设置；缺少可用度量时保持原有渲染。运行时不按每句字幕截图取样。

主、副轨分别排版和校正，背景外侧按首、末行行高补齐留白；同一文件内非空的中英分行也采用各行校正。内部行距、字号和同一行中英混排的共同基线保持原有规则。纯中文字幕保持原有像素；预设沿用已有独立校准。播放、幽灵字幕及精确合成继续共用绘制组件。

回归使用实际字体检查全大写、真正不含上伸字母的小写正文、上伸/下伸字母、中英主副轨互换、同文件分行及不同字号和缩放，同时检查基线不随英文句子变化。字形本身的自然差异不等同于每句紧贴墨迹边界的机械居中。
