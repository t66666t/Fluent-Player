# Fluent Player 1.0.0

本版本用于私有仓库内的安装与测试，下载需要仓库访问权限。

## 功能

- 整理本地视频、音乐与播客，保存播放位置并管理播放队列。
- 双语字幕、逐句阅读、字幕编辑、语音识别、OCR 与翻译。
- 管理 Bilibili、网盘和网页媒体下载，按需连接自己的 AI 服务。
- 使用 FluentPack、局域网传输与同步功能迁移媒体和配置。

## 这次发布的调整

- 修复 iOS Python runtime 重复准备时的符号链接复制失败，补齐 Apple 原生插件配置。
- Linux 分别面向 Ubuntu 22.04 / 24.04、Debian 12 / 13 构建，捆绑匹配的 mpv、FFmpeg / ffprobe 与依赖，修复插件运行库路径。
- 修复 Linux 数据目录识别、文件选择和启动窗口处理，补充原生文件导入、播放与冷启动检查。
- 纳入当前本地的播放、字幕、下载、本地模型及拖放功能修订。
- Windows 提供 Inno Setup 安装器和免安装目录包；Android 保留原发布签名。
- 附件统一标注版本与架构，并提供 SHA-256 校验和来源清单。

## 安装前请看

- Windows：x64，Windows 10 / 11；优先选择 setup.exe。ZIP 需完整解压，保留所有运行库。
- Android：ARM64，Android 7.0 及以上。已有用户直接覆盖安装，不必先卸载。
- macOS：macOS 14 及以上，按文件名选择 CPU 架构；尚未进行 Developer ID 公证。
- iOS / iPadOS：16.4 及以上。IPA 未签名，需要自己的有效签名，不能直接点击安装。
- Linux：x64，按系统选择 Ubuntu 22.04 / 24.04、Debian 12 / 13 对应的 DEB 或 tar.gz。DEB 使用 `sudo apt install ./文件名.deb`；目录包完整解压后运行 `fluent-player.sh`。不保证其他发行版、ARM 或所有显卡驱动可用。

升级前备份媒体库。不要将新旧目录包混在同一个目录，也不要因为签名或安装提示直接卸载旧应用。

完整说明：[安装与升级](https://github.com/t66666t/Video-master/blob/main/docs/installation.md) · [使用手册](https://github.com/t66666t/Video-master/blob/main/docs/user-guide.md)。

## 验证范围

这是构建产物发布，不代表已经完成五种系统的实机功能和覆盖升级验收。Windows 已检查安装包运行库依赖和后台工作进程启动；Android 已核对签名、版本和 ARM64 内容。发布时以实际构建日志和附带来源清单为准；设备驱动、覆盖升级和完整用户流程仍需在目标设备验收。

本次 Android 构建的可选 ASR NNAPI 加速组件因源码校验不匹配未启用，使用 CPU 路径。不要将打包成功理解为所有设备上的硬件加速均已验证。
