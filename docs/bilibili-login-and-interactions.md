# B 站登录与只读使用

本应用中的 B 站账号仅用于读取可访问的视频、画质、字幕及浏览信息。
软件内已移除点赞、取消点赞、投币、收藏夹编辑、关注与取消关注等账号互动，
也不再提供账号只读模式开关。需要互动时，使用视频页上的外部打开按钮，
在哔哩哔哩或浏览器中完成。

## 登录入口

| 系统 | 官方网页登录 | 环境要求 |
| --- | --- | --- |
| Android | 内嵌官方 H5 登录页，保留真实 WebView UA 并补充 Mobile 标记 | 系统 Android WebView |
| iOS | 内嵌官方 H5 登录页 | WKWebView |
| Windows | 内嵌官方桌面登录页，使用独立临时 WebView2 配置目录 | Microsoft Edge WebView2 Runtime |
| macOS | 内嵌官方桌面登录页 | WKWebView |
| Linux | 独立 Chromium/Chrome 窗口，通过本机 CDP 读取该独立会话 | 已安装 Chromium 或 Google Chrome，存在桌面会话 |

五个平台优先提供网页登录，并保留扫码和 Cookie 入口。
网页与接口使用应用的 B 站网络设置；网页登录不读取密码、短信或验证码表单。
原生 CookieManager / CDP 读取同一登录容器的 Cookie，nav 验证后才替换应用会话。
登录态仍保存在系统安全存储，重启后恢复；退出登录清除本机保存的会话。

二维码的 Set-Cookie 与官方 HTTPS 回跳参数逐项合并。
只读登录不要求投币等互动所需的 bili_jct，但仍要求 SESSDATA 并经 nav 验证。
验证失败或网络异常时保留原来的账号。已有 Cookie 中的浏览器设备信息和票据继续保留，
用于正常的内容读取，不生成或伪造网页登录票据。

## 互动功能删除范围

- 删除互动按钮、状态控制器、投币及收藏夹弹窗、互动错误反馈与账号写入服务。
- 删除点赞、投币、收藏、关注状态查询，以及仅供这些功能使用的设备验证和震动逻辑。
- 删除设置字段、注册项、导出项、账号页快捷入口及设置页开关；启动时清除旧版只读偏好。
  旧版曾关闭只读模式的用户也无法重新开启软件内互动。
- 视频统计仍展示接口返回的公开计数，只作信息展示；UP 主行保留主页入口并用箭头提示可进入。
- 详情加载及离线页不再显示互动占位；标题、UP 主、统计与导入、下载、外部打开、复制链接自然衔接。

## 保留的功能

登录验证与退出、搜索、UP 主主页、播放与清晰度切换、字幕和弹幕读取、
手动与自动导入、下载、分 P 与合集跳转、缓存管理和本地搜索／观看历史继续使用原有流程。
观看历史与播放进度仍由应用本地维护。

## 读取账号收藏夹

哔哩哔哩页面顶部的收藏夹按钮与账号页的“B 站收藏夹”进入同一页面。
登录后分页读取当前账号创建的收藏夹及夹内内容，包含账号有权访问的私密收藏夹；
首次进入加载，顶部刷新按钮与下拉刷新重新读取，返回收藏夹列表时更新夹名、封面和数量。
夹内刷新也读取收藏夹信息，因此名称变化可以在当前页面生效。

列表复用 UP 主子页面的分页、骨架和过渡，以及共用的视频行、自适应列数、封面缩略图、
占位图和图片显示组件。分页浏览沿用最多 50 页的限制；整夹导入和全选读取全部分页，
不受此浏览限制影响。失败保留已显示的内容，
刷新失败后的重试仍读取第一页。空收藏夹与不可访问、登录失效、网络及风控失败分别处理。
切换账号或退出时立即清空该页面的数据，并丢弃旧账号尚未完成的异步响应。

视频点击、导入及选择导入位置复用现有入口；播放时自动导入仍遵循原设置，
续播、分 P、字幕、弹幕、播放列表、下载和缓存继续走原流程。
失效视频与其他收藏类型保留展示，但不进入播放和导入。
浏览与刷新不会导入、下载、删除媒体库内容或修改本地播放进度。
新增的收藏接口只发送 GET，不包含新增／移除收藏或编辑收藏夹的操作。

刷新层保留平台原有的惯性、边界和回弹，再允许短列表下拉；只有当前列表从顶部
开始的下拉才触发刷新，上滑惯性及分页不触发刷新。多选期间暂停刷新。

收藏夹列表行和夹内顶部均提供“导入”及“选择导入位置”。整夹导入复用合集任务的
入库结构，在目标位置创建以收藏夹命名的目录，包含所有可导入视频及全部分P。
完整分页读取失败时不发布部分任务；失效及非视频内容跳过并显示数量。

夹内右上角的多选按钮或长按视频进入多选。点击视频改为切换勾选，失效与非视频
不可选；全选会读取尚未浏览的分页，显示进度并支持取消，不改变当前浏览位置。
底栏沿用媒体库文件夹的选择栏样式，只提供“导入默认位置”和“选择导入位置”。
多选导入直接复用单视频入库，导入全部分P，不增加收藏夹外层目录；整批只确定
一次目标位置。成功项清除选择，失败项保留供重试，返回键优先退出多选。
取消、退出页面或账号切换会停止后续操作，已完成的卡片保留。两种批量导入均不
修改保存的默认位置，也不自动下载视频。

相关测试为 `bilibili_favorites_service_test.dart`、`bilibili_favorites_screen_test.dart`
和 `bilibili_favorites_import_test.dart`，覆盖只读会话、完整分页、重复分页、
滚动停止、刷新、全选及取消、目标选择、目录结构、全部分P、卡片复用、失败重试
和账号切换。底栏的默认行为另由原有选择栏用例回归。
设置 `BILIBILI_FAVORITES_PREVIEW=1` 可生成手机、大字体、横屏及桌面预览，
含多选状态，输出到 `.artifacts/bilibili-favorites/`。

本次在 Windows 开发环境完成验证：收藏夹相关 60 项测试、四组布局预览及涉及的

## 验证

相关回归用例覆盖旧偏好迁移、登录验证与重启恢复、无 CSRF 的扫码登录、
已登录／未登录时详情面板不请求账号互动状态、离线与重试、
导入按钮、外部打开与复制链接、账号页及设置页在窄屏、横屏和大字体下的布局。
网络验证使用模拟响应，不向真实账号发送互动请求。

布局预览由 `bilibili_readonly_layout_test.dart` 与 `bilibili_video_links_test.dart` 生成，
分别设置 `BILIBILI_READONLY_PREVIEW=1` 和 `BILIBILI_VIDEO_LINKS_PREVIEW=1` 即可启用。
测试与分析日志位于 `.artifacts/bilibili-readonly-*.log`；
账号／设置页预览位于 `.artifacts/bilibili-readonly/`，视频详情预览位于 `.artifacts/bilibili-video-links/`。

手工回归建议：

1. 旧版关闭过只读模式的安装升级后，确认设置页和账号页均没有该开关或入口。
2. 使用网页、扫码或 Cookie 登录，关闭并重启应用，确认会话仍可读取；退出后确认已清除。
3. 在 B 站详情中检查公开统计、UP 主入口、导入、下载、外部打开和复制链接；确认没有互动按钮。
4. 播放可访问的视频，切换分 P、清晰度和字幕；断网后查看已下载内容与重试提示。
5. 检查搜索历史、观看历史、自动导入偏好及缓存清理仍正常工作。
