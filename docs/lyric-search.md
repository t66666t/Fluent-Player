# 音乐播放器歌词搜索

## 与 Lyricify 的结合方式

参考项目：[WXRIW/Lyricify-Lyrics-Helper](https://github.com/WXRIW/Lyricify-Lyrics-Helper)，
分析版本为 `e875781e2e889d97c3c518fe388decd14805a56f`。

该项目把歌曲搜索与匹配、在线数据获取、歌词解码、格式解析、歌词优化和时间轴处理分开。
这种分层适合本播放器，但它是 .NET 库，直接引用会给 Flutter 的桌面和移动端增加运行与打包依赖。
因此本功能用 Dart 适配必要的在线接口，复用播放器已有的 `TimedSubtitleParser`、
`LyricFileCodec`、`SubtitleTimedSpan`、双字幕播放和任务字幕存储。

来源请求结构的改写已注明出处，许可证和说明见 `third_party/lyricify/`。

## 用户流程

1. music player screen 的字幕管理中打开独立的歌词搜索窗口。
2. 本地文件可读取内嵌歌名、作者/歌手；没有标签时使用清理后的媒体标题。
3. 作者可修改。默认合并“歌名”和“歌名＋作者”的搜索候选；“仅搜歌名”可关闭作者辅助。
4. “从文件名选词”提供快捷片段，也可拖选或长按实际文件名中的文字搜索。
5. 结果优先按当前文件与候选的**毫秒级时长差**递增排列；差值相同时再比较歌名和作者。
   候选时长未知时排在已知时长之后；当前文件时长未知时使用名称匹配排序。
6. 打开时并行搜索三个平台，并预先获取歌词。每首歌词确认可用后立即加入列表，同时标出逐字/逐句和中文翻译；可直接预览、导入，不必等待同平台的其他歌曲。无同步歌词的歌曲被过滤；网络获取失败单独计数并提示重试。平台筛选只操作已加载结果，预览直接读取缓存。
7. 可设置整数毫秒偏移：正值延后、负值提前，原文、翻译及逐字时间同步移动。
8. “导入并应用歌词”保存到当前媒体的字幕目录，并设置原文主轨和可选的中文副轨。

打开窗口不会自动应用搜索结果。仅歌名或作者文本的匹配无法确认是否为现场版、翻唱或剪辑版，
所以需要用户预览后选择，结果会显示歌手、专辑、来源、时长、与本地文件的差值，以及逐字/逐句和中文翻译标记。

## 来源与时间轴

| 来源 | 原文 | 中文翻译 |
| --- | --- | --- |
| 网易云音乐 | 优先 YRC 逐字；不可解析时回退 LRC 逐句 | 优先使用 YRC 对应的翻译时间轴；有数据时回退普通翻译 |
| QQ 音乐 | 优先解码 QRC；失败时回退普通逐句接口 | 从 QRC 包装或普通接口获取 |
| LRCLIB | 只接受同步歌词 | 当前接口不提供独立中文翻译 |

纯文本没有时间轴时不能导入，也不会人工均分时间伪造逐字歌词。
原文与翻译使用各自的来源时间轴，沿用现有双字幕对齐机制，不按数组位置强行配对。
QRC 解码放在后台 isolate；QQ 不规范的 XML 外包装只提取有效的内容元素解析。解密轮次中的 32 位输入置换采用精确整数运算，避免每一位都分配大整数；64 位块置换仍使用 BigInt。

## 保存与并发

原文与翻译保存为兼容现有工具的 SRT。真实逐字时间通过 `.wordtiming.json` 附属文件保存，
继续使用现有加载、转移和删除生命周期。中文轨登记其原文资产关系及 `zh` 语言。
重复导入产生独立文件，不覆盖旧版本；不导入翻译时不会保留上一版本作为当前副轨。

歌曲切换后，旧窗口不能把歌词应用到新歌曲。请求取消和请求代数避免旧搜索结果覆盖新查询。
元数据读取不会覆盖用户已输入的歌名/作者，也不探测或下载远程媒体。
联网使用应用已有的 `NetworkHttp`，归入“其他联网功能”网络设置。
三个来源并行，同一来源里的“歌名”和“歌名＋作者”按顺序请求。每个关键词返回的候选立即去重并开始获取歌词，与下一关键词的搜索重叠执行。超时、连接失败、429/5xx，以及来源暂时没有返回有效数据时，每个请求最多尝试 3 次。歌词详情的瞬时网络失败同样重试，明确无同步歌词的结果不重试。只有用户取消这次搜索才会中止全部来源；网络切换造成的取消只重试该来源。

QQ 音乐最多同时读取 4 首歌词，网易云和 LRCLIB 各最多 2 首，三个平台独立准备。补充搜索的新候选加入同一个队列，有空闲并发槽位时立即开始获取。每首成功后只通知结果区域更新，不重建整个弹窗；列表持续按时长差或匹配度排序，保留进度、不可用结果过滤和失败统计。同一窗口内切换来源或预览不重复联网。关闭窗口或开始新搜索会取消旧请求，并阻止过期详情加入新结果。

字幕管理和歌词搜索的尺寸由 Dialog 的可用约束决定，键盘只避让一次，不叠加额外的尺寸动画。被子页面遮住的窗口保持原尺寸；播放器屏蔽键盘尺寸变化，封面和歌词不随输入法逐帧重排。手动字幕、翻译输入、接口设置和在线搜索采用按需订阅屏幕尺寸的方式，避免键盘变化重建整个表单。

## 验证

- `test/lyric_search_service_test.dart`：时间轴解析、回退、中文可用性、时长优先排序、作者扩展检索、瞬时失败重试、来源隔离、取消。
- `test/lyric_media_metadata_test.dart`：媒体标签、作者回退、原始文件名、缺失文件与远程路径。
- `test/lyric_search_importer_test.dart`：真实保存、双轨应用、逐字数据重新加载、重复导入及歌曲切换。
- `test/music_lyric_search_dialog_test.dart`：三平台预加载、缓存筛选、不可用结果过滤、逐首显示与并发上限、补充候选入队去重、键盘动画重建次数，以及预览导入、过期请求保护和响应式窗口。
- `test/music_subtitle_management_screen_test.dart`：字幕管理与子页面操作、响应式布局，以及连续键盘动画中后台播放器和被覆盖管理页不重建、不改变尺寸。
- `test/lyric_search_live_test.dart`：通过 `LYRIC_SEARCH_LIVE=1` 显式运行真实联网验证和本地媒体标签探测。

在线接口的可用性和某首歌曲是否有逐字/翻译取决于来源；搜索窗口会显示实际获取能力。
Apple Music、Spotify 等需要凭据的来源及更复杂的歌词优化暂未接入。
