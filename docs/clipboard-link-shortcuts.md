# 剪贴板链接快捷入口

启动完成或应用回到前台时，由应用根部的唯一监听器检查剪贴板。
下载、浏览器、播放、设置、文件夹等功能页面均可触发，不要求返回媒体库首页；
首页被替换或销毁后，监听和去重会话仍然有效。

有其他弹窗、底部面板、新手引导、页面转场或返回手势时延后检查。
根导航和可见媒体库的嵌套导航共用同一弹窗门控；被其他功能页遮住的
媒体库弹窗不会阻止当前功能页的提示。待界面稳定后重新读取最新剪贴板，
不会继续展示已经过时的异步结果。不轮询后台剪贴板，也不会每切一个页面都读取。

## 自动检测开关

媒体库设置中的“自动检测剪贴板链接”统一控制 B 站与其他来源，默认开启。
B 站提示和普通分流弹窗中使用反向勾选项“不再自动检测剪贴板链接”：
自动检测开启时不勾选，关闭时勾选，始终同步同一个正向设置值。

勾选后先显示“关闭自动检测？”确认框，告知可在
“媒体库设置 → 自动检测剪贴板链接”重新开启。确认前不修改设置；取消、
返回或点击遮罩均恢复原状态。确认关闭会立即停止后续自动检查，但保留当前
链接提示，导入、播放及忽略操作仍然可用。取消勾选则立即恢复自动检测，
无须再次确认。

从媒体库设置关闭时撤下自动检测提示、停止新的剪贴板读取，并使尚未完成的
自动读取和 B 站预览失效。当前提示内确认关闭只保留本次已经展示的操作，
不会允许新的自动读取或预览；没有新增开关或改变原有设置的存储含义。
已经提交给系统或共享服务的操作可能稍后结束，但结果不会再触发弹窗。
在任意页面重新开启后，即按去重规则检查最新剪贴板；若设置弹窗尚未关闭，
则在弹窗关闭后检查，不必回到首页、重启或再次切换应用。

开关保存到设备设置并随设置导出；连续切换以最后一次选择为准。
去重偏好改名为“避免重复弹出剪贴板提示”，默认开启；说明为
“同一次复制只提示一次，重新复制后可再次提示。”沿用 `skipRepeatedClipboardText`
存储键和导出位置，主开关关闭时保留该偏好并禁用切换。
手动粘贴、解析和已在运行的下载任务不受此自动检测开关影响。

媒体库设置中的“识别剪贴板”是主动操作：关闭设置页面后显示同一分流入口，
可以重新识别同一内容，也可在自动检测关闭时使用，不会开启自动检测开关。
无可识别链接时给出简短反馈；连续点击合并，不叠加窗口或重复返回页面。

## 桌面链接拖入

Windows、macOS、Linux 可将浏览器链接或含链接的文字拖到应用普通区域，
弹出同一分流入口；标题为“拖入的链接”。B 站保留原有已登录预览和操作，
抖音仍不提供通用下载页。

复用现有 `DesktopTextDropHost` 与原生拖放接收器，不重复注册窗口接收器。
只有鼠标释放时才提取、分类链接。先用当前画面的命中结果确定落点：
输入框及其装饰、图标、只读、禁用、密码和数字输入区域不进入全局分流。
可编辑区域继续执行既有插入/追加规则；字段拒收或内容未变化也不会回退成链接弹窗。
遮挡或隐藏在其他页面中的字段不参与落点判断，文件事件继续交给原有导入逻辑。

浏览器提供目标 URL 时，以目标为准，忽略显示文字中其他网站的链接；
没有目标 URL 才从纯文字中提取。无效的目标不使用显示文字来猜测。
保留完整路径、签名、重复参数和片段，沿用剪贴板提取器的数量与长度限制。

拖入是主动操作，关闭“自动检测剪贴板链接”后仍然可用；拖入弹窗内的勾选项
只修改自动检测偏好，不取消本次主动操作。拖入处理不读取剪贴板文字、不改写系统剪贴板，
仅读取原生更新标识，用于与紧随其后的自动提示合并，
也不覆盖旧版最后处理剪贴板原文记录。

已有弹窗时按拖入顺序排队，转场或后台状态结束后继续处理原来拖入的地址；
不以之后的剪贴板替换它。相同待处理批次只保留一次，最多 32 个待处理批次，
满额时明确提示稍后再拖入。一次提示结束后，可以再次主动拖入同一地址。
已展示拖入批次记录当时的更新标识和批次指纹；只有随后剪贴板仍是同一次更新、
且链接批次相符时才合并自动提示。重新复制会再次允许提示；拖入其他地址不会
覆盖最近一次真正处理的剪贴板记录，也不会使未变的剪贴板重新弹出。
拖拽及其窗口获得焦点期间延后自动检查，落在输入框时不叠加剪贴板提示；
之后真正离开并返回应用仍正常检查。

## 分流

- 普通 HTTP/HTTPS 网页：浏览器导入、通用下载页。
- 抖音来源域名：抖音下载页、浏览器导入；不提供通用下载页。
  通过实际 URL 主机匹配 `douyin.com`、`iesdouyin.com` 及它们的真实子域名，
  子域名必须以 `.douyin.com` 或 `.iesdouyin.com` 结尾；不以路径、短码、
  端口或能否下载作为来源分类条件。URL 本身仍须是格式有效的 HTTP/HTTPS 地址。
  例如 `https://v.douyin.com/GDXYOBTL3... X@m.qE` 会识别抖音来源，
  传入的地址保留末尾 `...`，不包含空格后的分享口令；如果地址实际已被截断，
  不尝试补全或声称可以解析。分流过程不展开短链接、不验证内容存在。
- Apple Podcasts、小宇宙频道/单集、喜马拉雅专辑/单集：增加播客解析页。
- RSS/feed 地址模式：作为订阅源候选提供播客入口，不声称内容已经确认为播客。
- 已登录的单个 B 站视频、番剧、课程、短链接：保留已有播放、卡片和下载操作。
  未登录或预览失败时仍可选择浏览器和通用下载页。
- 多条链接合并到一个选择框，可以切换地址和相应入口。

除已有的 B 站预览分支外，提示前不请求网页、不展开短链接、不启动解析器。
抖音、播客和通用下载页面接收原始完整地址并填入输入框；用户在页面内发起解析。
浏览器入口直接打开用户选择的地址，包括已保留旧原生浏览器会话的情况。

## 提取和去重

提取器独立于手动输入页面的宽松规则，不用句子中的数字、关键词或 ID 片段猜网站。
仅整段为 B 站 ID 时保留裸 ID 兼容。未知无协议域名、内网地址、文件和其他协议静默跳过。

抖音按真实域名分流，播客按已登记域名与路径提供入口；
外站参数、路径或 Markdown 显示文字中的网站名称不算来源证据。
Markdown 使用实际目标地址；限定还原分享文本的 `https\://` 和 Markdown 标点转义。
保留路径、签名、查询顺序、重复参数、百分号编码和片段；不删除跟踪参数。
标点边界有歧义时不靠裁剪参数推测媒体类型。

每段文本最多 256K 字符、每条地址最多 8192 字符、每次最多 32 个候选。
超限时不截断网址或自动弹出不完整批次，仍可使用各页面手动导入。

去重以“剪贴板的这次更新”为单位，不以历史 URL 为单位。
`clipboardPromptSnapshotV2` 只保存最近一次已提示更新的文字/批次 SHA-256 指纹和
可跨进程使用的更新标识，另可有一个尚未核对的拖入批次确认；不复制原文、
签名 URL，不导出为用户设置。旧的 `clipboardPromptLinkHistoryV1` 200 条历史
不再参与判断。旧版最后处理原文仅用于一次兼容基线，今后不再更新该原文记录。

| 平台 | 更新信息 | 范围 |
| --- | --- | --- |
| Windows | `GetClipboardSequenceNumber` + 启动 UUID、登录身份和窗口站 | 同次启动/登录内跨进程；不能取得启动标识时回退为进程内标识 |
| macOS | `NSPasteboard.changeCount` + 启动 UUID、用户 | 能取得启动标识时跨进程；否则在本进程内区分重新复制 |
| iOS | `UIPasteboard.changeCount` + 启动 UUID | 能取得启动标识时跨进程；否则在本进程内区分重新复制 |
| Android 26+ | `ClipDescription.timestamp` | 记录实际复制时间；仅在前台通过现有读取入口访问 |
| Android 24/25 | 剪贴板变更回调的进程内编号 | 本进程内区分重新复制；跨进程用文字指纹保守去重 |
| Linux X11 | 选择所有者提供的 `TIMESTAMP` + 启动 UUID、显示会话 | 支持该目标时跨进程；不支持或超时则回退 |
| Linux Wayland | 文字指纹回退 | 重新获得焦点可能重新提供同一选择，不能把该事件直接当成重新复制 |

原生接口按需调用，不新增轮询、后台读取或网络请求。读取文字前后核对更新标识，
复制恰好发生在读取中间时最多重试三次，避免把旧文字和新编号混在一起。
同一进程中编号未变时复用已读快照，已提示编号直接跳过文字读取、提取和哈希。
接口缺失、暂时失败、无法得到稳定版本或原生结果迟到均不破坏当前操作；
接口恢复不会把同一内容当成新复制弹出。取消或过期的读取不覆盖较新的快照。

开启去重时：关闭提示后反复回到软件、重启软件，未变化的那次复制保持安静；
新复制即使文字、URL 完全相同也允许提示，A → B → A 也允许。
同一链接提示已经可见时重新复制相同批次，合并到当前窗口，不在关闭后追加同一提示。
只有弹窗首次可见并完成一帧展示后才记为已提示；忽略、返回和点击遮罩都算已提示。
被其他页面挡住或预览中断的检查不提前写记录。关闭去重偏好后，每次真正回到前台
可再提示一次，同一次进入仍合并重复触发；两项开关同步生效并按最后一次切换保存。

系统或来源软件未报告实际更新时，完全相同的文字无法证明发生过重新复制；
此时保守保留防打扰行为，使用“识别剪贴板”或主动拖入即可重新呼出，不要求先复制其他文字。
