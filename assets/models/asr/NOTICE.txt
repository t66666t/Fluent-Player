Speech probes

Source: https://github.com/ggml-org/whisper.cpp/blob/b0a11594aec50892a02cd8d129eee2dfe93a8bb8/samples/jfk.wav
Source repository: MIT License, see https://github.com/ggml-org/whisper.cpp/blob/master/LICENSE
The original US federal government speech is a public-domain recording.

speech_probe_zh.wav: Application-authored test sentence, synthesized using the
Windows Microsoft Huihui Desktop system voice (16 kHz mono PCM).
Text: 欢迎使用本地语音识别，这是一段用于检查模型的测试语音。

Downloaded ASR and translation weights are not part of these bundled samples.
