Fluent Player adapts the provider request structures for QQ Music, NetEase
Cloud Music and LRCLIB into a Dart implementation in
lib/features/lyrics/lyric_search_service.dart. The NetEase adapter uses the
HTTPS plain API variants, and the Flutter implementation adds cancellation,
partial-source error reporting, synchronized-lyrics validation, previews,
and integration with the application's existing subtitle storage.

The .NET library itself is not bundled or required at runtime.
